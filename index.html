Incolla l'indirizzo della cartella che contiene le foto nel campo qui sopra. Il bucket deve consentire la lettura pubblica dei file e il loro elenco.

Come rendere pubblici i file per usarli qui

La galleria legge il bucket direttamente dal browser, senza un server nel mezzo: servono due permessi pubblici e una regola CORS.

  • lettura dei file (s3:GetObject), perché le foto si possano aprire;
  • elenco dei file (s3:ListBucket), perché il sito sappia quali foto ci sono;
  • CORS che consenta richieste GET dall'origine del sito (vedi il README del progetto).

Bucket intero pubblico. Se il pannello del provider offre un interruttore "accesso pubblico in lettura" sul bucket, è la via più semplice: di solito attiva insieme lettura ed elenco su tutti i file.

Solo una cartella, bucket privato per il resto. Serve una bucket policy che conceda i due permessi solo sul prefisso della cartella, lasciando privato tutto il resto:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadFolder",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-bucket/photos/*"
    },
    {
      "Sid": "PublicListFolder",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::my-bucket",
      "Condition": {
        "StringLike": { "s3:prefix": ["photos/*"] }
      }
    }
  ]
}

Sostituisci my-bucket e photos/ coi tuoi. Alcuni provider S3-compatibili usano una sintassi diversa per indicare bucket e oggetti nella risorsa: la struttura della policy (principal, azione, risorsa, condizione) resta questa, ma per il formato esatto va controllata la loro documentazione. Va poi aggiunta la regola CORS descritta nel README.

Attenzione: chiunque conosca l'indirizzo può vedere ed elencare i file resi pubblici in questo modo. Tieni fuori dalla cartella pubblica ciò che non deve essere condiviso.
